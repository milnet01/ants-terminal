# ANTS-1254 — `last_audit_summary` MCP tool

**Status:** spec stub — design phase. Surfaced by cold-eyes pass 3
(token-reduction lane M3) as a missed high-leverage candidate in the
1247-1252 pack.
**Source:** cold-eyes pass 3 finding, 2026-05-12.
**Predecessor pack:** ANTS-1247..1252 (other token-reduction tools).

## 1. Problem

`/audit` runs produce two artefacts:
- A SARIF JSON file (machine-readable, large: typically 50-500 KiB).
- An HTML report (human-readable, also large).

When Claude consults "what's broken right now?", today's flow is
`Read tools/audit/reports/audit.html` → ~5-15 K tokens. Most of that
is CSS, chrome, snippets, and per-finding boilerplate the assistant
doesn't need.

An MCP tool returning a compact summary:
```jsonc
{
  "ok": true,
  "run_at": "2026-05-12T08:13:00Z",
  "counts": {"critical": 0, "high": 2, "medium": 7, "low": 14, "info": 23},
  "top_findings": [
    {"severity":"high", "rule":"clazy-no-trivial-copyable-in-list",
     "file":"src/foo.cpp", "line":42, "message":"…"},
    ...
  ],
  "sarif_path": "/abs/path/to/audit.sarif",
  "html_path":  "/abs/path/to/audit.html"
}
```

…is ~200 tokens. **Saving per audit consultation: ~5-15 K tokens.**

## 2. Surface

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `top_n`     | int    | `5`  | Cap on `top_findings[]`. Server-clamp ≤ 50. |
| `severity_floor` | string | `"low"` | One of `"critical" / "high" / "medium" / "low" / "info"`. Findings below this floor are excluded from `top_findings[]` but counted in `counts`. |

Error codes follow `docs/standards/mcp-errors.md`:
- `not_audited` — no audit has run; no SARIF on disk. `state` family.
- `bad_severity_floor` — `severity_floor` not in enum.

## 3. Invariants (sketch)

- **INV-1.** Reads SARIF only — never the HTML (HTML is render-only,
  SARIF is canonical).
- **INV-2.** SARIF parse cached by mtime (same pattern as ANTS-1117).
- **INV-3.** `top_findings[]` sorted by severity descending, then by
  finding's confidence score (auditdialog field), then by file path.
- **INV-4.** `counts` always reflects the full finding set, not the
  filtered `top_findings[]`.
- **INV-5.** Reachability gate inherits from UDS + MCP socket; no new
  auth surface.

Full INV-set + RAM budget + step→verify left for the full spec.

fire.** Frequency: ~1-3 per session that touches audit; cumulative
~10-40 K per such session. Schema cost: ~80 tokens permanent.
