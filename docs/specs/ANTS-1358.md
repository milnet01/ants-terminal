# ANTS-1358 — `debt_sweep` detector expansion

Addendum to `docs/specs/ANTS-1113.md` (DebtSweepEngine v1). Adds four
detectors and grows `applyMechanicalFix` from a single hard-coded
branch into a per-detector auto-fix table. Pure-function philosophy,
git-invocation discipline, and the `Finding` triple
(`detector_id + file + line`) are inherited unchanged from v1.

## 1. Motivation

v1 shipped seven detectors but only `orphan_q_unused` was
mechanically fixable. The roadmap asked to widen the
mechanically-fixable set and add age/quality detectors.

## 2. Detectors added

| detector_id | category | auto-fixable | source enumeration | dependency |
|---|---|---|---|---|
| `stale_todo` | code_drift | no (flag-only) | `git ls-files` source exts + `git blame --line-porcelain` | git |
| `duplicate_include` | code_drift | **yes** (delete redundant line) | `git ls-files *.cpp *.h` | none |
| `obsolete_qstring_idiom` | code_drift | **yes** (rewrite line) | `git ls-files *.cpp *.h` | none |
| `dead_branch_after_return` | code_drift | no (flag-only) | `git ls-files *.cpp *.h` | none |

Mechanically-fixable detector count: **1 → 3**.

### 2.1 `detectStaleTodos`
Flags TODO/FIXME/XXX/HACK markers whose `git blame` committer-time is
older than `ScanOptions.staleTodoMaxAgeDays` (default 180; `<= 0`
disables). Distinct from `detectAddedTodos`, which is diff/scope-based
(markers *added* since `sinceRef`). Self-disables on non-git checkouts
(blame returns empty → file skipped). Flag-only: a stale TODO needs
human judgement, not a delete.

### 2.2 `detectDuplicateIncludes`
Flags the second and later occurrences of an identical `#include`
target (the `"x.h"` / `<x>` token, verbatim) within one file. Tracks
preprocessor conditional depth and only considers top-level includes,
so an include duplicated across mutually-exclusive `#if` branches is
never flagged. Auto-fix: delete the redundant line, after re-confirming
an earlier line still includes the same target.

### 2.3 `detectObsoleteQStringIdioms`
Flags removed-in-Qt6 QString idioms with an unambiguous mechanical
replacement. Table:

| find | replace |
|---|---|
| `QString::null` | `QString()` |
| `toAscii` | `toLatin1` |
| `fromAscii` | `fromLatin1` |

Auto-fix rewrites **every** table entry on the cited line in one pass
(idempotent: a second apply finds nothing left and returns
`file_changed`).

Soundness: the find patterns are anchored to code usage and callers
strip `//` line-comments, so a quoted/commented *mention* of the idiom
is largely excluded. `detectObsoleteQStringIdioms` additionally skips
`src/debtsweepengine.{cpp,h}` — that file *defines* the idiom table, so
its tokens are data, not occurrences, and an auto-fix there would
corrupt the detector. A residual: other files that name the idioms in
string literals or fixtures (e.g. this detector's own test) are still
flagged — ordinary triage noise consistent with the other flag-only
detectors, never auto-applied without an explicit per-finding call.

### 2.4 `detectDeadBranchAfterReturn`
Flags a statement immediately following an unconditional control-flow
exit (`return …;` / `break;` / `continue;` / `throw …;`) within the
same block. Conservative line-local heuristic: the exit must be the
*entire* line (conditional `if (x) return;` carries a leading keyword
and is excluded), and the next non-blank/non-comment line must not be a
structural token (`}`, `case`, `default`, label, `#…`, `else`,
continuation `)`/`,`, `*/`). Flag-only — deleting "dead" code is
unsafe (macros, `[[fallthrough]]`, multi-line constructs).

## 3. Deviations from the roadmap premise (verified 2026-05-20)

The roadmap floated `unused_include (cppcheck-driven)`,
`dead_branch_after_return (clazy-driven)`, and `obsolete_qstring_arg
(Qt6 conversion lints)`. On inspection:

- **cppcheck has no unused-include check** — its id list carries
  `missingInclude` / `missingIncludeSystem` and `unusedVariable` /
  `unusedFunction` / `unusedStructMember`, but nothing for unused
  includes. `include-what-you-use` (the tool that *does* this) is not a
  project dependency. A true unused-include analysis needs a compiler
  frontend. → Implemented the **redundant-duplicate** subset, which is
  deterministic, dependency-free, and safely auto-fixable.
- **clazy-standalone needs a `compile_commands.json` + resolved
  include paths** to run, and its `qstring-arg` combine-fixit is not
  unconditionally safe (arg-index reuse). → Implemented the
  removed-API subset whose replacement is byte-deterministic, with no
  external tool. `dead_branch_after_return` is a dependency-free
  conservative heuristic, flag-only.

Net: same intent (expand the detector set; widen mechanical
fixability) with deterministic, dependency-free sources and no unsafe
auto-fixes. The external-tool-driven supersets (iwyu unused-include,
clazy dead-code/qstring fixits gated on a compile DB) are deferred —
see ROADMAP ANTS-1358 fold-in.

## 4. Invariants

- **INV-14.** `detail::scanDuplicateIncludes` returns one
  auto-fixable Finding for a file that includes the same header twice;
  the Finding line is the *second* occurrence; empty when each header
  appears once; includes inside `#if`/`#endif` branches are not
  flagged.
- **INV-15.** `applyMechanicalFix` deletes the redundant include line
  for a `duplicate_include` Finding (verdict `applied:true`), and
  returns `file_changed` when the cited line is no longer a duplicate
  include.
- **INV-16.** `detail::scanObsoleteQStringIdioms` returns auto-fixable
  Findings for `QString::null`, `toAscii`, `fromAscii`; empty for
  `QString()` / `toLatin1` / `fromLatin1`.
- **INV-17.** `applyMechanicalFix` rewrites the obsolete idiom in place
  (`QString::null` → `QString()`) for an `obsolete_qstring_idiom`
  Finding (verdict `applied:true`); a second apply returns
  `file_changed`.
- **INV-18.** `detail::scanDeadBranchAfterReturn` flags a non-auto-fixable
  Finding for a statement after a bare `return …;`; empty when the
  following line is `}` / `case` / `default:` / a label / `#…`, and
  when the `return` is conditional (`if (x) return;`).
- **INV-19.** `detectStaleTodos` flags a TODO whose blame committer-time
  is older than the threshold, not auto-fixable; returns empty when
  `staleTodoMaxAgeDays <= 0` and on non-git trees.
