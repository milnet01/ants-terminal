# ANTS-1250 — `git_state` MCP tool (consolidated; status / log / diff)

**Status:** spec, ship-ready after cold-eyes pass 2 fix-pass.
**Source:** user-2026-05-12 (token-reduction priority).
**Cold-eyes pass 2 decisions** (2026-05-12):
- **Collapsed three verbs into one tool** (`git_state(op, …)`) per
  user pick — saves ~120 permanent schema tokens vs three separate
  registrations, reduces dispatch/setter/test boilerplate ~70%.
- Hardened argv handling per security lane findings.
- Realigned latency budgets (index-cold vs index-warm) per perf lane.

**Siblings:** ANTS-1247, 1248, 1249, 1251, 1252.

## 1. Problem

Claude calls `git status`, `git log`, `git diff` dozens of times per
session for orientation. Bash output is human-formatted (column
alignment, color codes stripped client-side, trailing newlines).
Per-call samples on this repo (2026-05-12):

| Bash today | Bytes | ~Tokens |
|------------|------:|--------:|
| `git status --porcelain=v1 -b` | 177 | ~44 |
| `git log --oneline -n 10` | 661 | ~165 |
| `git diff --stat HEAD~5..HEAD` | 1 753 | ~438 |

A single `git_state(op, …)` MCP tool collapses framing across all
three and skips downstream parsing.

## 2. Surface — one tool, three ops

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `op`    | string | required | `"status"` / `"log"` / `"diff"`. |
| `n`     | int    | `10`     | Used by `op:"log"` only. Server-clamp to `[1, 100]`. |
| `path`  | string | `""`     | Used by `op:"log"` and `op:"diff"`. Canonical-startswith guard via shared `pathInRepoRoot()` helper (ANTS-1248). |
| `range` | string | `""`     | Used by `op:"diff"` only. Required for diff. **Stricter regex below.** |
| `body`  | bool   | `false`  | Used by `op:"log"` only. When `true`, include full commit body (each body capped at 1 KiB per INV-3). |

### 2.1 Response — `op:"status"`

```jsonc
{
  "ok": true,
  "op": "status",
  "branch": "main",
  "upstream": "origin/main",
  "ahead": 2,
  "behind": 0,
  "files": [
    {"path":"src/foo.cpp", "index":"M", "worktree":" "},
    {"path":"docs/specs/ANTS-1247.md", "index":"A", "worktree":" "}
  ],
  "untracked": ["tests/features/scrollback_spinner_dedup/"]
}
```

### 2.2 Response — `op:"log"`

```jsonc
{
  "ok": true,
  "op": "log",
  "commits": [
    {"sha":"cb766ea", "subject":"ANTS-1246: Tasks chip…", "date":"2026-05-12"},
    ...
  ],
  "truncated": false
}
```

`truncated: true` iff a commit exists beyond `n` that we did not
return (i.e. the project has ≥ n+1 reachable commits matching the
path filter).

### 2.3 Response — `op:"diff"`

```jsonc
{
  "ok": true,
  "op": "diff",
  "range": "HEAD~5..HEAD",
  "files": [
    {"path":"src/claudetasklist.cpp", "added": 41, "removed": 6}
  ],
  "totals": {"added": 59, "removed": 10, "files": 2}
}
```

## 3. Implementation

- One helper `gitwrap.{h,cpp}` wrapping `QProcess::start("git",
  argv)` (shell-less argv list, never `bash -c`). Shared by all
  three ops + by ANTS-1251's `subsystem.recent_changes`.
- All three ops are a single public method `cmdGitState(const
  QJsonObject &req)` on `RemoteControl`. Internal dispatch on
  `op` field; one MCP tools/list entry; one tools/call dispatch
  case; one provider lambda; one setter.
- Output stream-parsed line by line — `gitwrap` buffers chunks
  from `readyReadStandardOutput`, splits on `\n` until consumed.
- **No libgit2 dep** — shelling to `git` is a ~30-line wrapper
  vs. ~500 lines of bindings.

## 4. Invariants

- **INV-1.** `cmdGitState` dispatches on `op` ∈ {"status", "log",
  "diff"}; anything else → `{ok:false, code:"bad_op"}`.
- **INV-2.** `op:"status"` parses `--porcelain=v1 -b` output; the
  `## branch...origin/branch [ahead N, behind M]` header line is
  parsed into `branch`/`upstream`/`ahead`/`behind`.
- **INV-3.** `op:"log"`: `n` server-clamped to `[1, 100]`; when
  `body:true`, each per-commit body capped at 1 KiB (truncate with
  `…` suffix).
- **INV-4.** `op:"diff"`: `range` is regex-validated against the
  **stricter** pattern: `^[a-zA-Z0-9._/^~][a-zA-Z0-9._/^~\-]*(\.\.\.?[a-zA-Z0-9._/^~][a-zA-Z0-9._/^~\-]*)?$`.
  First char of each rev-component **excludes `-`** (closes the
  cold-eyes S1250-1 leading-`-` flag-injection). Failure →
  `{ok:false, code:"bad_range"}`.
- **INV-5.** **Argv-separator INV.** Every git invocation places
  `--` between options and user-derived positional arguments (range,
  path). Paths beginning with `-` are additionally prefixed with
  `./`. Per `docs/standards/coding.md` argv-injection rule.
- **INV-6.** Shell-less `QProcess::start("git", QStringList args)`
  (the StringList overload, not the single-string overload). Test
  asserts no `bash -c`, `/bin/sh`, `system(`, `popen(` in
  `gitwrap.cpp`.
- **INV-7.** Stderr capture capped at 4 KiB; populated only in the
  `ok:false` branch.
- **INV-8.** `path` (when non-empty) is canonical-startswith
  validated via shared `pathInRepoRoot()` helper. Bytes < 0x20
  rejected with `code:"bad_path"`.
- **INV-9.** `git` not on PATH → `{ok:false, code:"git_missing"}`
  at call time (tools/list still exposes the tool).
- **INV-10.** Non-zero git exit → `{ok:false, code:"git_failed",
  stderr:"…"}` with stderr capped per INV-7.
- **INV-11.** Not a git repo → `{ok:false, code:"not_git_repo"}`
  (renamed from earlier `not_a_repo` for consistency with
  `not_<thing>` pattern; per cold-eyes M1/M2 error-code naming).
- **INV-12.** Wall-clock kill: `QTimer::singleShot(5000, …)` fires
  `terminate()`; 200 ms grace then `kill()`. Two-tier kill mirrors
  ANTS-1248 INV-5.
- **INV-13.** Reachability gate inherits from UDS + MCP socket
  (per ANTS-1132); no new auth surface.

## 5. Memory & perf

- **Memory:** per-call O(output bytes). `git log --oneline` cap at
  100 commits × ~70 B + 1 KiB body × 100 = ~107 KiB worst-case
  with `body:true`. `git diff --stat` for long ranges is bounded
  by `git`'s own output, stream-parsed.
- **Per-call latency**:
  - Index-warm: ≤ 30 ms p50 (fork + parse).
  - Index-cold (first call after large checkout / rebase): ≤ 200 ms
    p95 (git index read; calibrated against 9k-line ROADMAP repo).
  - Hard kill at 5 s + 200 ms grace (INV-12).
- **No cache** — git state changes too fast for safe caching at
  this layer.

**MCP inputSchema (sketch, to verify the ~120 token claim):**

```jsonc
{
  "name": "git_state",
  "description": "Query git repo state (status / log / diff) as structured JSON. Replaces multiple Bash invocations.",
  "inputSchema": {
    "type": "object",
    "required": ["op"],
    "properties": {
      "op":    {"type": "string", "enum": ["status", "log", "diff"]},
      "n":     {"type": "integer", "minimum": 1, "maximum": 100, "default": 10, "description": "log only"},
      "path":  {"type": "string", "description": "log/diff: filter to this repo-relative path"},
      "range": {"type": "string", "description": "diff: e.g. HEAD~5..HEAD"},
      "body":  {"type": "boolean", "default": false, "description": "log: include commit body"}
    }
  }

```

Estimated rendered size: ~480 chars = ~120 tokens. ~1/3 of the
three-tool design's permanent cost (per §1).

Error codes follow `docs/standards/mcp-errors.md`: `bad_op`,
`bad_range`, `bad_path` (input); `git_failed`, `git_missing` (tool);
`not_git_repo` (state).

## 8. Risks / mitigations

| Risk | Mitigation |
|------|-----------|
| Argv injection via `range` or `path` | Strict regex + `--` separator + `./` prefix for `-`-leading paths (INV-4/5). |
| Worktrees / submodules | V1: pass through git's native handling; document. |
| `git status` of a non-git dir | INV-11 — return `not_git_repo` cleanly. |
| Output > 4 MiB | stdout streamed line-by-line; stderr capped at 4 KiB (INV-7). |
| Slow git on huge ranges | 5 s + 200 ms kill (INV-12). |
| Per-commit body unbounded | 1 KiB per-body cap (INV-3). |

## 9. Out of scope (V1)

- **File-level diff body** — not just stat. Defer: token cost much
  higher; most callers want stat first to decide which files to
  read in full.
- **`git blame`** — separate verb shape; not orientation use-case.
- **`git stash list`** — niche; defer until requested.
- **Submodule recursion** — defer; v1 treats submodules as files.
- **`git show <sha>`** — defer; can be composed via `read_file` +
  `op:"log"`.
