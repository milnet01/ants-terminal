# ANTS-1252 — token-saving hook pack

**Status:** spec, ship-ready after cold-eyes pass 2 fix-pass.
**Source:** user-2026-05-12 (token-reduction priority; user note:
"another CC session said hooks are free").
**Cold-eyes pass 2 hardening:**

  tmpfile **before** rename (S1252-1, S1252-5).
- `sessionId` regex-validated before any filesystem interpolation

- Drift-check refuses to write outside a sane project root

  (S1252-4).

  user-globally must detect "is this an ants repo?" and exit silent
  otherwise — S1252-7).
- INV-6 rewritten to sentinel-key uninstall (M6: marker comments

- Token-math reframed: ~110 K/week claim double-counted ANTS-1247;
  reduced to a calibrated range with explicit dependency notes

## 0. "Are hooks free?" — calibrated answer

Mostly yes, with a clear boundary. Per the Claude Code hooks docs
(fetched 2026-05-12 from `docs.claude.com/en/docs/claude-code/hooks`):

| Event | Stdout cost | Mechanism |
|-------|------------:|-----------|
| **UserPromptSubmit** | text size in tokens | Prepended to user prompt before model sees it. |
| **PreToolUse** (`decision: "approve"` / no decision) | 0 | Tool runs as if no hook. |
| **PreToolUse** (`decision: "block"` + `reason`) | reason size, once | Reason injected back to model; counts once per block. |
| **PostToolUse** | text size, once per tool run | Appended to tool result. |
| **Stop** | 0 (output ignored) | Side-effect-only event. |
| **PreCompact** | 0 (output ignored) | Same. |
| **SessionStart** | text size, once per session | Prepended like UserPromptSubmit. |

So *truly free*: Stop, PreCompact, and any PreToolUse/UserPromptSubmit
that exits silently. *Cheap-per-fire*: PreToolUse block reasons,
PostToolUse augmentations. *Per-session*: SessionStart and
UserPromptSubmit injections.

## 1. The pack — five hooks

| # | Event | Script | Cost class |
|---|-------|--------|-----------|
| 1 | **SessionStart** | `ants-session-preamble.sh` | per-session injection |
| 2 | **PreToolUse** (Bash) | `ants-bash-veto.sh` | per-veto |
| 3 | **PreToolUse** (Read) | `ants-read-roadmap-veto.sh` | per-veto |
| 4 | **Stop** | `ants-drift-check.sh` | FREE |
| 5 | **PreCompact** | `ants-precompact-snapshot.sh` | FREE |

Scripts live in `hooks/` at repo root. Install via
`tools/install-hooks.sh`.

**Per-project gate (applies to every script).** All five hooks ascend
from `$PWD` looking for a `.ants-project` marker file (committed to
repo root), bailing at the user's home directory. **No `git
rev-parse` fork** — a sentinel-only ascent is one `stat` per
ancestor (typically 1-3) at < 1 ms total, vs `git rev-parse`'s
~5-15 ms cold fork. INV-9 codifies this and lists belt-and-braces
rejected roots (`/`, `/home`, `/root`, `/tmp`, `$HOME`) the marker
must NOT be at. Hooks installed user-globally only fire when an
`.ants-project` marker is reachable from the cwd — non-ants sessions
pay a sub-millisecond stat, never tokens.

**Threat model on the marker** (loop-3 S1252-9 / S1252-10): the
`.ants-project` file is a **UX gate, not a security boundary**.
Same-UID write is already game-over for any shell hook on the
system; the marker commits the policy "hooks run only where I've
opted in" but does NOT defend against a malicious clone that ships
its own marker — that's the user's job to review in `git diff`
after clone. The marker is committed (visible in `git status`) so
review is straightforward.

### 1.1 `ants-session-preamble.sh` — SessionStart

Emits a compact orientation block once per session:

```
[ants:project] branch=main ahead=2 behind=0 last="ANTS-1246: …"
[ants:next-up] ANTS-1247 (status filter); ANTS-1248 (workspace_search)
[ants:tests] 311 features, last run: all green (2026-05-12)
```

Cap: **≤ 500 bytes total stdout** (INV-3) — even when the resume
snapshot from PreCompact is present.

### 1.2 `ants-bash-veto.sh` — PreToolUse(Bash)

- Reads the proposed command via `jq -r '.tool_input.command // empty'`
  from stdin (INV-7: never regex on raw JSON).
- Decoded value pattern-matched against:
  - `grep -r ... src/`, `find src/ -name` → suggest `workspace_search`
  - `git status`, `git log --oneline`, `git diff --stat` → suggest
    `git_state`
  - `cat ROADMAP.md | grep` → suggest `roadmap_query`
- Block reason ≤ 200 bytes (INV-4).
- **Override: trailing comment `# ants-bypass`** — veto strips the
  comment before display; does NOT pass through to bash. Compare
  with the earlier-considered `ANTS_BYPASS=1` env-var prefix
  (rejected in loop 3 — too easily exfiltrated as a reusable
  sentinel; if Claude memorises it the veto loses its function).
  Comment form keeps the bypass intentional and removes the literal
  token from the block-reason text the model sees (INV-12).
- **Security framing (loop-3 S1252-8):** the bypass is a **UX
  affordance, not a security boundary**. Hooks do not defend against
  prompt injection that relays a bypassed bash command; the security
  boundary remains the UID gate + UDS perms (ANTS-1132). Stated
  explicitly so future readers don't assume otherwise.

### 1.3 `ants-read-roadmap-veto.sh` — PreToolUse(Read)

Read target ≡ project-root `ROADMAP.md` and file size > 50 KiB →
block with reason "use `mcp__ants__roadmap_query` (status=active
saves ~10× tokens)".

**No env-var override** — same loop-3 H1 concern as §1.2 (a stable
sentinel token can be memorised and leaked). The Read tool input
shape is just a `file_path`, so there's no in-band comment-form
analogue to `# ants-bypass`. **Escape path:** Read with `offset`
and `limit` (built into the Read tool) for a partial slice — the
veto only fires on full-file reads. Callers that genuinely need the
full ROADMAP (release-notes generation, etc.) can call
`roadmap_query` with `status: "all"` for the same content at
~12 K tokens (vs. ~123 K for the Read).

### 1.4 `ants-drift-check.sh` — Stop

Side-effect-only. **Project-root sanity (INV-9)**: refuses to write
`.ants-audit-pending` outside a recognised ants-project root.
Scans turn-touched files via `jq` on `transcript_path`, runs
`tools/audit/drift-check.sh`, writes the marker on findings, exits
0 always. Logs to `~/.cache/ants-terminal/drift-check.log` so
backgrounded errors are recoverable (cold-eyes L8). Uses
`flock` on a PID-file to prevent overlapping runs (M5: zombie
processes from `&` backgrounding).

### 1.5 `ants-precompact-snapshot.sh` — PreCompact

Side-effect-only. Parses `transcript_path` and writes most recent
TodoWrite snapshot + in-progress spec path to
`~/.cache/ants-terminal/precompact_<sessionId>.json` ONLY if
`sessionId` matches `^[a-zA-Z0-9_-]{1,64}$` (INV-2). Otherwise exits
silent.

## 2. Install path

`tools/install-hooks.sh`:

1. **lstat target** (`~/.claude/settings.json`). If `S_ISLNK`,
   abort with a clear "settings.json is a symlink — resolve
   manually before installing" (INV-5 — closes S1252-1).
2. **Backup with `cp --no-dereference`** to
   `settings.json.ants-backup` (preserves symlink semantics; doesn't
   accidentally follow a malicious link target).
3. Read settings; splice in our config under sentinel key
   `"ants_hooks_pack_v1": true` plus the five hook entries (each
   pointing at `~/.claude/hooks/ants-*.sh`). Marker fences via
   JSON-key sentinel — **not** `// BEGIN/END` comments, because
   `jq` strips JSON comments (M6 / INV-6).
4. Write to **tmpfile** (`settings.json.tmp` in same dir for
   atomic-rename guarantees).
5. **Validate the tmpfile BEFORE rename**: `jq empty
   settings.json.tmp` (exit non-zero on parse fail). If validation
   fails, leave settings.json untouched and abort (INV-8 — closes
   S1252-5).
6. `rename(tmpfile, settings.json)` only after validation succeeds.
7. Copy `hooks/*.sh` to `~/.claude/hooks/`, but **skip if existing
   target is a symlink** or has identical contents.
8. Print summary of actions.

Idempotent: re-running detects sentinel key + unchanged scripts,
no-op writes (INV-1).

Uninstall (`--uninstall`): remove sentinel key + the named hook
entries; remove `~/.claude/hooks/ants-*.sh`. Marker fence via key
removal — not text-fence (key removal is robust to `jq`
re-serialisation).

## 3. Invariants

- **INV-1.** All five hooks exit 0 on the no-op path. Test runs
  each with `printf '{}\n'` as stdin and asserts exit 0.
- **INV-2.** `sessionId` (PreCompact, drift-check use) validated
  against `^[a-zA-Z0-9_-]{1,64}$` before any filesystem
  interpolation. Failure → exit 0 silent. (Closes S1252-2.)
- **INV-3.** `ants-session-preamble.sh` stdout ≤ 500 bytes.
- **INV-4.** `ants-bash-veto.sh` block reason ≤ 200 bytes.
- **INV-5.** Install script aborts if `settings.json` is a symlink
  (`lstat` check). (Closes S1252-1.)
- **INV-6.** Install / uninstall use sentinel-key fencing
  (`ants_hooks_pack_v1` JSON key), not text-fence comments. Marker
  surface is `jq`-stable.
- **INV-7.** Hooks parse payloads via `jq -r '<path>'` only, never
  regex on raw JSON. Test fixture asserts the bash-veto script
  uses `jq` (source-grep). (Closes S1252-4.)
- **INV-8.** Install script validates tmpfile with `jq empty`
  **before** rename; failure leaves `settings.json` untouched.
  (Closes S1252-5.)
- **INV-9.** Per-project gate: every hook script aborts (exit 0
  silent) if `git rev-parse --show-toplevel` is missing, equal to
  `/`, `/home`, `/root`, `/tmp`, `$HOME`, OR if the resolved root
  does not contain a `.ants-project` marker file. (Closes S1252-3
  and S1252-7.)
- **INV-10.** Side-effect-only hooks (Stop, PreCompact) emit zero
  bytes to stdout (assert via `bash <hook> </dev/null | wc -c` = 0
  in test).
- **INV-11.** Drift-check uses `flock` on a PID-file under
  `~/.cache/ants-terminal/` to prevent overlapping runs; second
  invocation skips if first is still running.
- **INV-12.** Bash-veto block-reason text MUST NOT contain the
  literal bypass token. The override mechanism is documented in
  `hooks/README` only; reason text references it by description
  ("see hooks/README for override"). Closes loop-3 H1 leakable-
  bypass-token concern.

## 4. Memory & perf

- **Per-hook latency** (after dropping `git rev-parse` from the gate,
  loop-3 Perf-H1 fix):
  - SessionStart: ≤ 50 ms hot, ≤ 150 ms cold (bash + jq + git
    status for preamble content, not for the gate).
  - PreToolUse hooks: ≤ 20 ms p99 cold, ≤ 8 ms p50 hot. The gate
    is sentinel-only (1-3 `stat` calls); cold bash+jq spawn is
    ~5-15 ms.
  - Stop: ≤ 100 ms return (drift check forks to background under
    flock).
  - PreCompact: ≤ 30 ms file write.
- **Non-ants session overhead** (hooks installed user-globally fire
  but exit silently per INV-9): ~3-8 ms stat-ascent per PreToolUse
  fire (no fork). On a 50-Bash-call non-ants session: ~250 ms of
  cumulative gate overhead, 0 tokens. Acceptable given user-global
  install convenience.
- **Memory:** all under 5 MiB resident (bash + jq).

User-visible latency note: PreToolUse hooks **block Claude's tool
call** during their window. The 20 ms p99 budget is the worst
single-tool-call user-perceptible delay.

## 5. Token math — calibrated

### 5.0 Pack-wide permanent schema cost (loop 3 fix — Token-C1)

tools on top of the existing 8. Approximate permanent per-session

`tools/list`):

| Tool | Spec | Schema delta (tokens) |
|------|------|----------------------:|
| `roadmap_query` (status arg) | ANTS-1247 | +80-120 |
| `workspace_search`           | ANTS-1248 | ~150 |
| `file_outline`               | ANTS-1249 | ~120 |

(Without the 1250/1251 collapse this would have been ~860; the

saving. Recouped after first useful call in any session.

never enters per-session model context.

### 5.1 Per-hook scenarios

Saving depends on whether ANTS-1247 has shipped:

#### 5.1.a. With ANTS-1247 shipped (target end-state)

| Hook | Token cost | Saving signal | Net |
|------|-----------:|--------------:|----:|
| SessionStart preamble | ~80 / session | ~600-800 (4-5 Bash calls avoided) | **+520-720 / session** |
| Bash veto (per fire) | ~30 | ~300-2 000 (avoided grep output) | **+270-1 970 / fire** |
| Read-ROADMAP veto | ~30 | ~13 000 redirect → `roadmap_query` returns ~12 200 first time; thereafter `status=active` returns ~1 750 | **+30 / fire** (the veto signal); the saving lives in 1247 already |
| Stop drift check | 0 | Surfaces audit work without prompting | indirect |
| PreCompact snapshot | 0 | Smoother post-compact resume | indirect |

**Estimate** (5 sessions/week × 4-6 bash-vetos × 2 roadmap-vetos):
**~30-40 K tokens/week** — the Read-ROADMAP saving is owned by 1247,
not double-counted here.

#### 5.1.b. Standalone (1247 NOT yet shipped)

Read-ROADMAP veto's reason text is the same (~30), but the
alternative path (Read ROADMAP.md vs Bash-grep) burns ~30 K tokens
unredirected. Standalone saving on read-ROADMAP-veto: **~25 K /
fire**, but only one fire/session before model adapts. With 1248
+ 1252 only (no 1247): **~80-100 K / week**.

The pack's **actual headline saving** depends on which siblings
ship first. Recommended ship order: 1247 → 1248 → 1252 (so the
hook pack acts as the safety net once the canonical tools exist).

## 7. Risks / mitigations

| Risk | Mitigation |
|------|-----------|
| Hook breaks Claude (exit non-zero, hangs) | INV-1 (exit 0); 5 s `timeout` wrapper on every hook invocation. |
| Install script corrupts settings.json | Validate-before-rename (INV-8); lstat symlink check (INV-5); `cp --no-dereference` backup. |
| Cross-project pollution (hooks fire in non-ants sessions) | Per-project gate (INV-9): `.ants-project` marker + sane-toplevel check. |
| `sessionId` path-traversal | Regex `^[a-zA-Z0-9_-]{1,64}$` (INV-2). |
| Drift-check writes outside repo / runs as root | INV-9 sane-toplevel check rejects `/`, `/home`, `/root`, `/tmp`, `$HOME`. |
| jq missing on user host | All hooks degrade silently (exit 0 on `jq` failure) — INV-7's parse fails → script silently no-ops. |
| Zombie drift-check processes | `flock` PID-file gates overlap (INV-11); errors logged to `~/.cache/ants-terminal/drift-check.log` (so silent backgrounding doesn't hide failures). |
| Bash-veto JSON-injection | `jq -r` only (INV-7); pattern-match against decoded value, never raw JSON. |
| Veto blocks legitimate Bash | Trailing `# ants-bypass` comment lets Claude opt out per command (§1.2). The veto strips the comment before display — no token leakage (INV-12). |
| Veto blocks legitimate full Read of ROADMAP | Use `roadmap_query` with `status: "all"` (same content, ~12 K vs ~123 K) or Read with `offset`/`limit` for slices (§1.3). |

## 8. Out of scope (V1)

- **Hook editor UI** — defer to ANTS-1162's wizard. Per-spec wizards
  for hooks would duplicate effort.
- **Per-project hook scoping at install time** — V1 hooks are
  user-global with a project-root gate (INV-9). Scoping at install
  time would require an Ants-specific `.claude/` overlay; out of
  scope.
- **Non-bash hook implementations** (Python, Lua) — bash + jq is
  the minimum portable surface.
- **Telemetry** (counts of vetos fired) — useful but not first-cut;
  add when the pack matures.
