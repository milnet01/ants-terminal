# ANTS-1251 — `subsystem` MCP tool (consolidated; map / files / recent_changes)

**Status:** spec, ship-ready after cold-eyes pass 2 fix-pass.
**Source:** user-2026-05-12 (token-reduction priority,
specifically /indie-review).
**Blocked by:** ANTS-1250 (composes with `cmdGitState` for the
`recent_changes` op).
**Cold-eyes pass 2 decisions** (2026-05-12):
- **Collapsed three verbs into one tool** (`subsystem(op, …)`) per
  user pick — saves ~120 permanent schema tokens.
- Lane validation runs **before** any filesystem call (security
  S1251-1).
- Cache switched to **mtime-only** (no 100 ms TTL) so concurrent
  `/indie-review` reviewers all hit warm (perf H4).

**Siblings:** ANTS-1247, 1248, 1249, 1250, 1252.

## 1. Problem

`/indie-review` dispatches 5-8 reviewer subagents in parallel; each
currently reads CLAUDE.md (~3.5 K tokens) to find the Module map.
Measured 2026-05-12: 6 reviewers × ~3.5 K = ~21 K tokens spent on
the same content. A consolidated MCP tool with three ops pre-parses
the map, returns per-lane chunks, and exposes recent lane-scoped
history.

## 2. Surface — one tool, three ops

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `op`   | string | required | `"map"` / `"files"` / `"recent_changes"`. |
| `lane` | string | `""`     | Required for `"files"` and `"recent_changes"`. Must match a known lane name (validated before any filesystem call — INV-1). |
| `n`    | int    | `10`     | Used by `"recent_changes"`. Server-clamp `[1, 100]` (forwarded to `cmdGitState` op:"log"). |

### 2.1 Response — `op:"map"`

```jsonc
{
  "ok": true,
  "op": "map",
  "source": "CLAUDE.md",
  "lanes": [
    {"name":"vtparser",     "summary":"VT100/xterm state machine. Emits VtAction structs..."},
    ...
  ]
}
```

### 2.2 Response — `op:"files"`

```jsonc
{
  "ok": true,
  "op": "files",
  "lane": "terminalgrid",
  "files": ["src/terminalgrid.cpp", "src/terminalgrid.h"]
}
```

Resolution rule: files whose basename (with or without extension)
*begins with* the lane name. Example: lane `"audit"` resolves to
`auditdialog.cpp`, `auditdialog.h`, `auditengine.cpp`,
`auditengine.h`, `audithygiene.cpp`, `audithygiene.h` — caller picks.
Sorted lexicographically.

**No `max_*` arg / no `truncated` field** — file count is bounded
by the filesystem (typically 1-6 files/lane); a cap would invent
a problem that doesn't exist. Different shape from 1248/1249/1250
which CAN unbound, hence have `truncated`. (Loop-3 Optim-O5 — the
asymmetry is intentional.)

### 2.3 Response — `op:"recent_changes"`

```jsonc
{
  "ok": true,
  "op": "recent_changes",
  "lane": "terminalgrid",
  "commits": [
    {"sha":"...", "subject":"...", "date":"..."}
  ]
}
```

Internally composes `cmdGitState({op:"log", n, path: "src/<lane>*"})`
(see §3) — no duplicated git plumbing. Hard-deps on ANTS-1250.

## 3. Implementation

- New `subsystemmap.{h,cpp}` for CLAUDE.md parsing.
- Parser walks `CLAUDE.md` and collects bullets under the `## Module
  map (src/)` H2 until the next H2. Each bullet is shaped as
  ``-`name` — summary text`` — the parser drops anything that
  doesn't match (defensive against format drift).
- **Cache: mtime-only.** Parsed `lanes[]` is cached keyed on
  `CLAUDE.md`'s mtime. No wall-clock TTL — CLAUDE.md doesn't change
  inside a `/indie-review` run, and the 100 ms TTL pattern (from
  ANTS-1117) is wrong for read-mostly docs. Concurrent reviewers
  all hit warm cache.
- `op:"files"`: lane name is **membership-checked against parsed
  `lanes[].name`** (INV-1) before any filesystem call. Glob runs
  only after validation. Per-result canonical-startswith re-check
  for defence in depth.
- `op:"recent_changes"`: delegates to `cmdGitState({op:"log", …})`
  (composition; no new git plumbing). All ANTS-1250 INVs apply.
- One public method `cmdSubsystem(const QJsonObject &req)` on
  `RemoteControl`; one MCP tools/list entry; one tools/call dispatch
  case; one provider lambda; one setter (collapse decision).

## 4. Invariants

- **INV-1.** Lane validation **precedes** any filesystem call.
  `op:"files"` and `op:"recent_changes"` test `lane` for membership
  in the parsed `lanes[].name` list. Unknown lane →
  `{ok:false, code:"unknown_lane", lanes:[...]}` (lanes echoed so
  caller can recover). No glob runs, no `cmdGitState` call.
- **INV-2.** Cache invalidates on `CLAUDE.md` mtime change only;
  no wall-clock TTL.
- **INV-3.** Parser drops bullets that aren't ``-`name` —`` shape
  (defensive against format drift).
- **INV-4.** `op:"files"`: result paths are canonical-startswith
  re-checked against project root (defence in depth — even though
  lane name is validated, a malicious symlink inside `src/` could
  still slip through if INV-1 alone is trusted).
- **INV-5.** `op:"recent_changes"` reuses `cmdGitState` — test
  asserts the composition by source-grep (no duplicated argv-build).
- **INV-6.** Reachability gate inherits from UDS + MCP socket; no
  new auth surface.
- **INV-7.** Empty CLAUDE.md (no Module map section) →
  `{ok:true, lanes:[]}` for `op:"map"`; `op:"files"`/`"recent_changes"`
  return `code:"unknown_lane"`.

## 5. Memory & perf

- **Memory:** parsed `lanes[]` cached at ~6 KiB. One copy in
  `RemoteControl`.
- **Per-call latency:** ≤ 5 ms cached; ≤ 30 ms uncached (one file
  read + parse). `op:"recent_changes"` adds ANTS-1250 budget on top.
- **Cache:** mtime-only — concurrent reviewer hits all share.
- **Concurrent first-call coalescing** (loop-3 Perf-M2): when 5-6
  reviewers fire `op:"map"` near-simultaneously the first warms the
  cache. The naive implementation lets each call race-parse
  independently (5 × 30 ms wasted work, but only ~150 KiB transient
  RAM; last-writer-wins on the cached array is idempotent because
  inputs are identical). Single-flight (`QMutex` + result-broadcast)
  is a follow-up only if benchmarking post-launch shows it matters.
  V1 accepts the race-parse cost as bounded and idempotent.

## 6. Token math

`/indie-review` typical run (6 reviewers, parallel dispatch):

| Step | Today (Bash/Read) | With `subsystem` tool |
|------|------------------:|----------------------:|
| Each reviewer learns lane partition | 6 × ~3.5 K = ~21 K | 6 × ~250 = ~1.5 K |
| Each reviewer finds lane files | 6 × ~400 (2 greps) = ~2.4 K | 6 × ~50 = ~300 |
| Each reviewer reads recent lane history | 6 × ~600 (git log) = ~3.6 K | 6 × ~150 = ~900 |
| **Total** | **~27 K** | **~2.7 K** |

**~24 K-token saving per `/indie-review` run.** No monthly
multiplier — cadence is user-driven, not scheduled. Permanent schema
cost: ~120 tokens (one tool, three ops) vs the prior 3-tool design's
~360 tokens.

## 8. Risks / mitigations

| Risk | Mitigation |
|------|-----------|
| CLAUDE.md format drift breaks parser | INV-3 (defensive drop); feature test against fixture copy of current Module map flips red on drift. |
| Lane name collision (multi-file match) | `op:"files"` returns sorted multi-match; caller picks. Document. |
| ANTS-1250 not landed yet | Blocked-by header; §10 sequences impl after 1250. |
| User's CLAUDE.md has no Module map | INV-7 — empty `lanes[]`, no error. |
| Malicious CLAUDE.md replacement same mtime | INV-2 is mtime-only; `touch -d` lets an attacker spoof. Acceptable: file is user-owned; same-UID modification means attacker already controls user account. |
| Path-traversal via lane | INV-1 (membership-before-glob) + INV-4 (canonical re-check). |

## 9. Out of scope (V1)

- Cross-project lane discovery — works only on the project owning
  CLAUDE.md. Defer because each project's Module-map shape may
  differ; multi-project would need a stable schema.
- Lane dependency graph — separate use-case, not orientation.
- Programmer-vs-layman view — Module map is a single shape; the
  two-view pattern lives in ROADMAP per ANTS-1154, not here.
