# ANTS-1343 — `consolidateMypyStubHints` finding-count preservation

## Problem

`src/auditdialog.cpp:2702` sets
`r.findingCount = kept.size() + r.omittedCount;` to reflect the N→1
collapse performed by `consolidateMypyStubHints` — but the immediately-
following call path at `:4039` unconditionally overwrites:

```cpp
AuditEngine::capFindings(r, kMaxFindingsPerCheck);
r.findingCount = r.findings.size() + r.omittedCount;
```

This clobbers the consolidator-authored value. UI labels then show the
post-collapse list size (typically 1, the synthetic "N missing stub
package(s)" hint) instead of the pre-collapse raw count (e.g. 23
mypy stub findings). The headline number on the audit summary table
loses ~95 % of the actual signal.

Source: indie-review-2026-05-14 lane-4 M2.

## Fix

Add an explicit "authored" flag on `CheckResult`:

```cpp
struct CheckResult {
    ...
    int  findingCount = 0;
    bool findingCountAuthored = false;  // ANTS-1343 — set by
                                        // consolidators that
                                        // override the default
                                        // arithmetic at :4039.
};
```

`consolidateMypyStubHints` populates the flag whenever it actually
collapses entries (`packages.size() >= 2`). The pre-collapse raw
count is preserved by computing it from the original `r.findings.size()`
at the head of the consolidator before reassigning the list.

The dispatcher at `:4039` gates on the flag:

```cpp
if (!r.findingCountAuthored)
    r.findingCount = r.findings.size() + r.omittedCount;
```

`capFindings` continues to update `omittedCount` independently, so a
consolidator that triggers AND a cap that triggers compose correctly:
the consolidator's pre-collapse count + the cap's omittedCount.

## Invariants

- **INV-1** `CheckResult` declares `bool findingCountAuthored = false;`
  initialised to false.
- **INV-2** A non-mypy `CheckResult` runs through the v1 path
  unchanged — `findingCount = findings.size() + omittedCount`.
- **INV-3** A mypy `CheckResult` with `packages.size() < 2` does NOT
  set the flag — single-stub case is not a collapse.
- **INV-4** A mypy `CheckResult` with `packages.size() >= 2` (N
  collapsed into 1 synthetic hint):
  - sets `findingCountAuthored = true`,
  - sets `findingCount` to the pre-collapse raw count (the original
    `r.findings.size()`).
- **INV-5** The dispatcher's post-cap line at `:4039` checks the
  flag and leaves `findingCount` alone when set.
