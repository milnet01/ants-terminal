# ANTS-1334 — Combining marks at wide-char right-edge attach to lead cell

## Problem

At `terminalgrid.cpp:383–399`, `handlePrint()` routes zero-width
combiners (`wcwidth(cp) == 0 && cp > 0x20`) to the previous cell.
When `m_wrapNext == true`, `targetCol = m_cursorCol` (delayed-wrap
contract: cursor sits ON the just-written character).

Failing scenario: wide char (charWidth=2) is written at
`cursorCol = cols-2`:

1. Lead cell lands at `cells[cols-2]` (`isWideChar=true`).
2. Continuation cell at `cells[cols-1]` (`isWideCont=true`).
3. `m_cursorCol += charWidth` → `cols`, clamped to `cols-1`,
   `m_wrapNext = true` (terminalgrid.cpp:456–460).

A subsequent zero-width combiner now takes the `m_wrapNext`
branch and stores to `combining[cols-1]` — the continuation cell.
The renderer looks combiners up by the lead column, so the
diacritic is invisible.

Common with CJK at right-edge positioning + non-English
input methods on any reasonable column count (e.g. 80, 132).
Regression class is "diacritic disappears at column N":
silent visual data loss, not crash.

## Invariants (post-fix)

- **INV-1.** When the resolved `targetCol` points to a
  `isWideCont` cell, decrement once to land on the lead before
  storing the combiner.
- **INV-2.** Only one decrement (a continuation cell cannot
  follow another continuation cell — single decrement always
  lands on a lead or a non-wide cell).
- **INV-3.** No change to the `m_wrapNext = false` /
  `m_cursorCol > 0` branches when the resolved target is already
  a lead cell or a normal cell — backwards-compatible.
- **INV-4.** Guarded against the boundary case `targetCol == 0
  && cells[0].isWideCont` (impossible per VT100 semantics — a
  continuation cannot start at col 0 — but the guard makes the
  invariant local).

## Test

`tests/features/combining_at_wide_right_edge/`:

1. Seed grid 80×24. Cursor to (0, 78). Write a wide CJK char
   (e.g. `U+4E2D` "中"). Lead at col 78, cont at col 79,
   m_wrapNext=true.
2. Write a combining diacritic (e.g. `U+0301` COMBINING ACUTE
   ACCENT, w=0).
3. Assert `cells[78].combining` carries the combiner (size > 0).
4. Assert `cells[79].combining` is absent / empty.
5. Repeat with `m_wrapNext=false`, cursor at (0, 79) after the
   wide write, combiner arrives → same invariant.

Label `features;fast`. GUI-free, links terminalgrid+vtparser only.

## Implementation

One conditional decrement inside the combiner branch.
