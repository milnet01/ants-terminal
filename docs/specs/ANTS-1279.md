# ANTS-1279 — `indie_review_orchestrate` MCP tool (single-call dispatch manifest)

**Status:** shipped 2026-05-22.
**Kind:** implement.
**Source:** indie-review-2026-05-13 (token + perf bundle).
**Siblings:** ANTS-1112 (engine), ANTS-1281 (brief manifest v2), ANTS-1288
(suggested_merges), ANTS-1352 (`indie_review_dispatch`).

## 1. Problem

A Claude-Code-driven `/indie-review` sweep currently calls
`indie_review_partition` once and then `indie_review_brief` once per lane
(~14 lanes) before it can dispatch the reviewer subagents — N+1 round-trips
and N nearly-identical orchestration steps the parent has to drive by hand.

## 2. Surface

One MCP tool, `indie_review_orchestrate`, that returns the entire dispatch
plan in a single call:

```jsonc
{
  "ok": true,
  "lane_count": 14,
  "reports_dir": ".indie-review/reports-<YYYY-MM-DD>",   // QDate::currentDate() at call time
  "lanes": [
    {
      "name": "vtparser",
      "summary": "...",
      "source_paths": ["src/vtparser.cpp", "src/vtparser.h"],
      "report_path": ".indie-review/reports-<YYYY-MM-DD>/vtparser.md",
      "brief": "<v2 manifest — no inlined source bodies>",
      "contract_docs": ["docs/standards/coding.md", ...],
      "byte_count": 1234
    }
  ],
  "suggested_merges": [{"lanes":["luaengine","pluginmanager"],"rationale":"identical summary text"}],
  "next_steps": "Dispatch one subagent per lane … then call indie_review_corroborate … indie_review_fold_in."
}
```

- Args: `caller_cwd` (Required, ANTS-1404 — empty `caller_cwd` refuses with
  `code:"caller_cwd_required"` at the dispatch gate), `include_briefs` (bool,
  default true — false yields a name/path-only skeleton).
- Refusals (handler-side, in order): `no_window` (no MainWindow),
  `no_project` (caller_cwd resolves to no project root), `no_lanes` (the
  partition is empty).
- Composition only: reuses `IndieReviewEngine::derivePartition`,
  `assembleBriefManifest` (v2, no inlined source bodies — ANTS-1281),
  and `suggestedMerges` (ANTS-1288). No new engine logic beyond the
  report-path stem + bundling.
- **Dispatch stays in the parent.** The MCP server cannot spawn Claude
  subagents; the tool returns a manifest and the parent fires its `Agent`
  tool per lane. This is the spec's resolution of the "dispatch manifest
  vs. server-spawn" open question — manifest, not spawn.
- **Collection reuses existing tools.** `reports_dir` + per-lane
  `report_path` (project-relative) compose with `indie_review_corroborate`
  (`reports_dir=`) and `indie_review_fold_in`. No new collect verb (would
  duplicate them).

## 3. Invariants

- **INV-1** — An empty partition → refusal `code:"no_lanes"` (not an empty
  manifest), after the earlier `no_window` / `no_project` guards (see § 2
  Refusals).
- **INV-2** — `lane_count == lanes.length`; one entry per derived lane.
- **INV-3** — `report_path` is `<reports_dir>/<stem>.md` where `<stem>` is
  the lane name with every non-`[A-Za-z0-9_]` run collapsed to a single
  `-`, then leading/trailing `-` trimmed; an all-punctuation lane name
  yields the literal stem `lane`. The stem is filesystem-safe and becomes
  `indie_review_corroborate`'s lane key directly (it reads each report's
  `completeBaseName()`) — so the key is this sanitized stem, not the
  original lane string; a comma-joined multi-name lane gets one combined
  stem.
- **INV-4** — `include_briefs:false` omits `brief` / `contract_docs` /
  `byte_count`; the skeleton (name / summary / source_paths / report_path)
  is always present.
- **INV-5** — Each `brief` is the v2 manifest (no inlined source bodies —
  ANTS-1281), keeping the bundled response compact.
- **INV-6** — `suggested_merges` mirrors `indie_review_partition`'s
  ANTS-1288 output for the same partition.
- **INV-7** — `next_steps` names `indie_review_corroborate` (with the
  emitted `reports_dir` and `min_lanes 2`) and `indie_review_fold_in` as
  the collect path.

## 4. Tests

`reports_dir` / `report_path` / `next_steps` / `include_briefs`

## 5. Notes — RAM / size budget

Response is bounded by `lane_count` (≤ ~30) × the v2 manifest brief
(~1–2 KB each, no source bodies) ≈ ≤ 60 KB worst case. `include_briefs:false`
drops it to a few KB. No caching, no member-state mutation — a pure read
composing existing engine functions.

`reports_dir` is date-stamped (`reports-<YYYY-MM-DD>`), so two sweeps on the
same day resolve to the same directory. The tool only *names* the dir; the
parent's subagents create and write the report files, so same-day overwrite
vs. append is a parent-side concern outside this tool's contract.
