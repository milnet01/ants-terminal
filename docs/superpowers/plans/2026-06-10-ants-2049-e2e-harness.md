# ANTS-2049 E2E User-Level Harness — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Let the agent launch a throwaway second Ants instance (`--e2e`), drive it with synthetic input over the RemoteControl socket, observe it (socket verbs + window-grab PNGs), and tear it down — without touching the user's running `build/` instance.

**Architecture:** Add a `--e2e` launch flag that forces the RemoteControl socket open and sets a `RemoteControl::m_e2eMode` gate; behind that gate add four socket-only `cmd*` inject handlers (`inject-key`, `inject-click`, `resize-window`, `grab-image`) to the `dispatch()` if-chain; add a generic `--remote-json` CLI passthrough so the shell harness can reach any verb (incl. the new arg-bearing ones) on a chosen socket. A shell driver (`tools/e2e/run.sh`) + smoke suite (`tools/e2e/smoke.sh`) launch/observe/teardown, wired as an opt-in `e2e` ctest label.

**Tech Stack:** Qt6/C++20, CMake+Ninja, RemoteControl `QLocalServer`/`QLocalSocket`, raw `QEvent` posting (no QtTest), bash.

**Contract:** `docs/specs/ANTS-2049.md` (accepted, cold-eyes loops 1–6 clean). INV-1..INV-9 there are the acceptance criteria. Read it alongside this plan.

**Live-session build rule (ANTS-2025):** the user's instance runs from `build/`. Build ONLY to `build-fast/` this session (`cmake --preset=fast && cmake --build --preset=fast`); never relink `build/`. Run the harness against `build-fast/ants-terminal`.

## Task 2: `--remote-json` passthrough (needed to drive the new verbs)

**Files:**
- Modify: `src/main.cpp` (the `--remote` client branch, near the hand-coded verbs ~:307-374)

- [ ] **Step 1:** Add a `--remote-json` value option to the parser. In the `--remote` client path, when `--remote-json` is set: parse its value with `QJsonDocument::fromJson`; require a top-level object with a string `cmd`; extract `cmd`, build `args` = the object minus `cmd`; call `RemoteControl::runClient(cmd, args, socketPath)` and return its exit code. On malformed JSON or missing `cmd`, print an error to stderr and return 1.

```cpp
// inside the --remote handling, before the existing cmd dispatch:
if (parser.isSet("remote-json")) {
    const QJsonDocument d = QJsonDocument::fromJson(parser.value("remote-json").toUtf8());
    if (!d.isObject()) { fprintf(stderr, "ants-terminal --remote-json: not a JSON object\n"); return 1; }
    QJsonObject o = d.object();
    const QString c = o.value("cmd").toString();
    if (c.isEmpty()) { fprintf(stderr, "ants-terminal --remote-json: missing \"cmd\"\n"); return 1; }
    o.remove("cmd");
    return RemoteControl::runClient(c, o, socketPath);
}
```

## Task 3: `e2eResolveTarget` helper (offscreen-safe widget resolution)

**Files:**
- Modify: `src/remotecontrol.h` (decl), `src/remotecontrol.cpp` (definition + needed includes: `<QApplication>`, `<QWidget>`)

- [ ] **Step 1:** Declare `QWidget *e2eResolveTarget(const QString &objectName) const;` (private).

- [ ] **Step 2:** Implement per spec §2.3: (1) `QApplication::activeModalWidget()` if non-null; else (2) first visible non-`m_main` widget in `QApplication::topLevelWidgets()`; then (3) if `objectName` non-empty, `top->findChild<QWidget*>(objectName)` (return nullptr if not found). MUST NOT call `QApplication::activeWindow()`.

```cpp
QWidget *RemoteControl::e2eResolveTarget(const QString &objectName) const {
    QWidget *top = QApplication::activeModalWidget();
    if (!top) {
        for (QWidget *w : QApplication::topLevelWidgets()) {
            if (w == m_main) continue;          // m_main is the MainWindow*
            if (!w->isVisible()) continue;
            top = w; break;
        }
    }
    if (!top) top = m_main;                      // fall back to the main window
    if (objectName.isEmpty()) return top;
    return top->findChild<QWidget*>(objectName); // nullptr → caller emits widget_not_found
}
```
(Confirm the `MainWindow*` member name on `RemoteControl` — likely `m_main`/`m_mainWindow`; use the real one.)

```cpp
const QString path = req.value("path").toString();
if (path.isEmpty()) return badArgs("grab-image", "path required");
const QByteArray dir = qgetenv("ANTS_E2E_ARTIFACT_DIR");
if (dir.isEmpty()) return badArgs("grab-image", "no artifact dir");
const QString root = QFileInfo(QString::fromLocal8Bit(dir)).canonicalFilePath();
auto chk = PathValidation::validatePath(path, root, "grab-image", "path");
if (chk.bad) return QJsonDocument(chk.err);        // bad_path
QWidget *t = e2eResolveTarget(req.value("widget").toString());
if (!req.value("widget").toString().isEmpty() && !t) return widgetNotFound("grab-image");
const QString out = chk.argvForm;                  // safe-for-fs form
if (!t->grab().save(out, "PNG")) return badArgs("grab-image", "save failed");
QJsonObject o; o["ok"]=true; o["path"]=out; return QJsonDocument(o);
```
