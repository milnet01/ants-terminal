## 0.6.0 — shipped (2026-04-14)

**Theme of the release:** make the two features that already make Ants
distinctive (plugins + audit) production-grade. No sprawl; polish what's
there before adding a multiplexer. Reference:
[CHANGELOG.md §0.6.0](../../CHANGELOG.md#060--2026-04-14).

### 🎨 Features

- ✅ [ANTS-4044] **Scrollback regex search**
  . `Ctrl+Shift+F` floating bar with
  three toggles — `.*` (regex), `Aa` (case), `Ab` (whole word,
  Alt+R/C/W) — plus match counter, next/prev jump, all-match
  highlight overlay, current-match accent, invalid-pattern feedback.
  Ghostty 1.3 parity.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4045] **OSC 9;4 progress reporting**
  . Parses
  `ESC ] 9 ; 4 ; state ; pct ST` (ConEmu / Microsoft Terminal), renders
  a thin colored strip along the bottom edge plus a tab-icon dot.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4046] **Click-to-move-cursor on shell prompts**
  (previously in code;
  docs promoted).
  Kind: implement.
  Source: planned.

- 💭 [ANTS-1001] **Kitty Unicode-placeholder graphics**
  (U+10EEEE + diacritics).
  Moved to 0.7 backlog — scope-wise a standalone item, not a blocker.
  Layman: Support another way of showing pictures in the terminal, the one the Kitty terminal uses.
  Kind: implement.
  Source: planned.

### 🔌 Plugins — manifest v2 + capability model

- ✅ [ANTS-4047] **Declarative permissions in `manifest.json`**
  — `permissions`
  array with first-load confirmation dialog, persisted per-plugin grants
  in `config.json` (`plugin_grants`). Un-granted permissions = missing
  API functions (not `nil` stubs) so plugins can feature-detect.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4048] **Per-plugin Lua VMs**
  — each plugin gets its own `lua_State`,
  10 MB heap budget, 10 M instruction hook. `PluginManager` fans
  events out over all loaded VMs.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4049] **`ants.settings.get / .set`**
  — gated by `"settings"`. Backed by
  `config.json`'s `plugin_settings.<name>.<key>`. Settings-dialog
  auto-render of `"settings_schema"` is follow-up (API + store in
  place).
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4050] **`ants.clipboard.write(text)`**
  — gated by `"clipboard.write"`.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4051] **Hot reload**
  via `QFileSystemWatcher` on `init.lua` /
  `manifest.json` / plugin dir. Fires `load` / `unload` lifecycle
  events. Enabled only when `ANTS_PLUGIN_DEV=1`.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4052] **Plugin keybindings**
  — `manifest.json` `"keybindings":
  {"action-id": "Ctrl+Shift+X"}` block. Firing the shortcut sends a
  `keybinding` event to the owning plugin.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4053] **`ants._version`**
  + **`ants._plugin_name`** exposed.
  Kind: implement.
  Source: planned.

### ⚡ Performance

- ✅ [ANTS-4054] **LRU glyph-atlas eviction**
  . Per-glyph `lastFrame` counter,
  warm-half retention on overflow, median-based fallback. See
  `glrenderer.cpp:compactAtlas`.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4055] **Per-line dirty tracking**
  (partial). `TermLine::dirty` set by
  grid mutations; `TerminalWidget::invalidateSpanCaches()` does
  targeted eviction of URL / highlight caches. Full cell-level
  render-path partial-update remains as future work — primitive is in
  place.
  Kind: implement.
  Source: planned.

- 💭 [ANTS-1002] **EGL_EXT_swap_buffers_with_damage + EGL_EXT_buffer_age**
  on the GL
  path. Deferred — narrow Mesa-only win, revisit in 0.9 platform pass.
  Layman: Redraw only the parts of the screen that actually changed, which saves power on some graphics drivers.
  Kind: refactor.
  Source: planned.

### 🔒 Security

- ✅ [ANTS-4056] **Multi-line paste confirmation**
  . Dialog on `\n` / `sudo ` /
  `curl … | sh` / control chars. Policy independent of bracketed-paste
  mode. Config key `confirm_multiline_paste` (default on).
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4057] **Per-terminal OSC 52 write quota**
  : 32 writes/min + 1 MB/min
  (independent of the 1 MB per-string cap).
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4058] **OSC 8 homograph warning**
  : when visible label's hostname ≠
  URL host, a confirm dialog shows both and requires opt-in.
  Kind: implement.
  Source: planned.

### 🧰 Dev experience

- ✅ [ANTS-4059] **`ants-terminal --new-plugin <name>`**
  — scaffolds init.lua /
  manifest.json / README.md from templates. Name validated against
  `[A-Za-z][A-Za-z0-9_-]{0,63}`.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4060] **`ANTS_PLUGIN_DEV=1`**
  — verbose logging on plugin scan/load,
  plus hot reload.
  Kind: implement.
  Source: planned.

- ✅ [ANTS-4061] **`--help` / `--version`**
  CLI flags wired via
  `QCommandLineParser`.
  Kind: implement.
  Source: planned.
